# 怎么把这个仓库推上 Gitee（5 分钟）

## 为什么不推 GitHub

本机实测 `github.com` 和 `raw.githubusercontent.com` **域名不通**（`git push` 会失败），但 `api.github.com` 通。所以走 Gitee。

---

## 步骤

### 1. 注册 / 登录 Gitee

https://gitee.com → 注册（用手机号即可）

### 2. 新建仓库

右上角 **+** → **新建仓库**

| 字段 | 填什么 |
|---|---|
| 仓库名称 | `xiaov-field-assistant` |
| 路径 | 会自动填充，保持 `xiaov-field-assistant` |
| 介绍 | `面向地理野外实习的多模型协同质检智能体` |
| 是否开源 | **公开**（要给别人看，必须公开） |
| 初始化仓库 | **不要勾**（勾了会生成 README，跟你本地的冲突） |
| 选择语言 | Python |
| .gitignore 模板 | **不选**（你已经有自己的了） |

点「创建」。

### 3. 拿到仓库地址

创建后会显示：

```
https://gitee.com/<你的用户名>/xiaov-field-assistant.git
```

### 4. 在本机执行

打开 cmd，依次执行（**把 `<你的用户名>` 换成你的**）：

```bat
cd /d C:\Users\zrfsh\Desktop\xiaov-field-assistant

git init
git add .
git commit -m "feat: 小V野外助教 - 多模型协同质检智能体"
git branch -M main
git remote add origin https://gitee.com/<你的用户名>/xiaov-field-assistant.git
git push -u origin main
```

第一次 push 会弹窗要账号密码 —— **Gitee 的密码要用「私人令牌」，不是登录密码**。
生成位置：Gitee → 设置 → 私人令牌 → 生成新令牌（勾 `projects` 权限即可）。

## 推送前必看：三条自检

### ✅ 1. 确认 config.json 没有你的私有端点

我已经把它换成占位符了，但你如果又跑了一次程序，可能会被覆盖。推送前查一下：

```bat
cd /d C:\Users\zrfsh\Desktop\xiaov-field-assistant
findstr /C:"token-plan" /C:"aliyuncs" /C:"qwen" /C:"sk-" 03_CONFIG_配置规则\config.json
```

**应该什么都没输出。** 如果输出了，把 `config.json` 改回占位符再推。

### ✅ 2. 确认 .gitignore 生效

```bat
git status --short
```

**不应该看到** `config.json`、`__pycache__/`、`output/`、`wheels/` 这些。
如果看到了，说明 `.gitignore` 没生效 —— 执行 `git rm --cached <文件名>` 后再提交。

### ✅ 3. 确认没有密钥进历史

```bat
git log -p | findstr /C:"sk-"
```

**应该什么都没输出。**

> 如果已经推上去了才发现有密钥：**立刻去平台轮换密钥**（旧的作废），光删文件没用 —— git 历史里还留着。

## 常见问题

| 现象 | 原因 | 怎么解决 |
|---|---|---|
| `git push` 卡住不动 | 网络问题 | 换手机热点试；或 `git config --global http.postBuffer 524288000` |
| `403 Forbidden` | 密码填错（用了登录密码） | 改用私人令牌 |
| `failed to push some refs` | 远端有文件（创建时勾了初始化） | `git pull --rebase origin main` 再 push |
| GIF 不动 | 文件没推上去或路径错 | 检查 `docs/demo.gif` 是否存在于仓库 |
| README 里图片 404 | 用了相对路径但目录层级不对 | README 里写的是 `docs/demo.gif`，确认文件在那个位置 |
